# Contributing

Keep changes factual, task-focused, and consistent with SiteRadian 1.0.0 behavior.

1. Create a focused branch.
2. Run npm ci, npm run build, and npm run verify.
3. Test navigation and layout at mobile and desktop widths.
4. Never commit real access tokens, private site URLs, internal validation evidence, or unpublished customer information.
5. Keep third-party product claims restrained and provide attribution for new brand assets.

Documentation examples must use example.com and the explicit placeholder siteradian_REPLACE_WITH_YOUR_TOKEN.
