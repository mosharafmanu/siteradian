# Security policy

Please report a suspected SiteRadian vulnerability privately through the repository owner’s GitHub profile. Do not open a public issue containing exploit instructions, access tokens, private site details, or personal information.

Include the affected version, reproducible steps that do not expose real credentials, expected behavior, and observed impact.

This website is static and has no account or application backend. Product security guidance is maintained at:

https://mosharafmanu.github.io/siteradian/security/
