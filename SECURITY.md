# Security policy

## Supported releases

| Release | Security support |
| --- | --- |
| SiteRadian 1.0.x | Supported |
| Pre-public product identities and older development builds | Not supported |

The public website documents the current SiteRadian release. Security fixes, when required, target the current supported release line.

## Report a vulnerability privately

Use [GitHub Private Vulnerability Reporting](https://github.com/mosharafmanu/siteradian/security/advisories/new). This is the preferred route because the report and follow-up remain private between the reporter and repository maintainers.

Do **not** disclose a suspected vulnerability in a public issue, pull request, discussion, screenshot, or tutorial comment. Do not include live access tokens, API keys, passwords, cookies, private keys, database credentials, customer data, or other secrets. Use non-production examples and redact private site details.

Helpful reports include:

- the affected SiteRadian version and relevant WordPress/PHP versions;
- the affected feature, integration, or security boundary;
- minimal steps to reproduce in a safe test environment;
- expected and observed behavior;
- practical impact and any known preconditions;
- sanitized logs, error codes, or screenshots when relevant.

## What to expect

We will acknowledge clear reports as availability allows, investigate reproducible findings, and coordinate remediation and disclosure when warranted. This policy does not promise an SLA, bounty, fix, or specific publication timeline.

Please allow a reasonable opportunity to investigate before public disclosure. Good-faith research should avoid privacy violations, service disruption, persistence, data destruction, unnecessary data access, and testing against sites you do not own or have explicit permission to assess.

## Website and product guidance

This repository hosts a static website with no SiteRadian account or application backend. Product security concepts are described at [SiteRadian Security](https://mosharafmanu.github.io/siteradian/security/). General support and product bugs should follow the [Support Center](https://mosharafmanu.github.io/siteradian/support/) rather than the private vulnerability route.
